# 其他可能机制与效应——补充分析

> 已有核心结论：插入玻璃板后，M₁ 需**远离** G₁ 才能恢复等厚条纹，根本原因是**视像位移效应**——玻璃板使 M₁ 的像向 G₁ 位移 $d(n-1)/n$，等效空气薄膜厚度不等于光程差为零的条件。
>
> 本文档继续搜集和梳理其他可能的相关机制、教学争议、以及从不同角度切入的分析，作为补充。

---

## 一、等效空气劈尖模型（深入）

### 1.1 核心思想

迈克尔逊干涉仪的干涉图样，完全等价于"两个虚面"之间的薄膜干涉：

- **虚面1**：M₁ 透过玻璃板和 G₁ 所成的最终虚像位置
- **虚面2**：M₂ 经 G₁ 半反射面所成的虚像 M₂'（位置固定）

等厚直条纹出现的条件是：这两个虚面**在空间中有交线**（即等效薄膜厚度在某处趋近于零）。

### 1.2 玻璃板对等效劈尖的影响

插入玻璃板前：
- M₁ 的虚像 = M₁ 自身位置（无折射介质）
- M₁ 虚像与 M₂' 交线 → 白光零级条纹出现

插入玻璃板后：
- M₁ 的虚像 ≠ M₁ 自身位置（折射使像向 G₁ 位移）
- 原来的交线位置不再对应零薄膜厚度
- M₁ 必须远离 G₁ 移动，使其虚像重新追上 M₂'

### 1.3 与光程差模型的本质区别

| | 光程差模型 | 等效劈尖模型 |
|---|---|---|
| 恢复条件 | $\delta = 0$ | 两虚面相交（$h = 0$） |
| M₁ 移动方向 | 靠近 G₁ | **远离 G₁** |
| 移动量 | $\Delta x = d(n-1)$ | $\Delta x = d(n-1)/n$ |
| 折射率公式 | $n = 1 + \Delta x / d$ | $n = d / (d - \Delta x)$ |
| 适用方法 | 数条纹法（等倾圆环吞吐） | **白光等厚条纹定位法** |

## 二、平行平板像位移的严格推导

### 2.1 Snell 定律出发

平行平板厚度 $d$，折射率 $n$，物体在平板后方距离 $u$ 处。

从平板前方观察该物体：

- 光线从物体发出，经平板折射后进入空气
- 在近轴近似下，像的纵向位移为：

$$\Delta = d\left(1 - \frac{1}{n}\right) = d \cdot \frac{n-1}{n}$$

**像比物体更靠近观察者**。

### 2.2 在干涉仪中的体现

从 G₁（半反射面）的位置向上看 M₁：

```
观察者（G₁位置）→ 空气 → 玻璃板（厚度d, 折射率n）→ 空气 → M₁镜面
```

M₁ 的表观位置（虚像位置）= M₁ 真实位置 − $d(n-1)/n$

### 2.3 这是标准几何光学结论

此公式在 Hecht《Optics》、Born & Wolf《Principles of Optics》、赵凯华《光学》等教材中均有推导，属于**平行平板成像的基本性质**，并非特殊假设。

## 三、潘峰（北邮）论文中的"两种方法"

### 3.1 论文信息

> 潘峰，《迈克耳孙干涉仪测平行玻片折射率的研究》，第四届全国高等学校物理实验教学研讨会论文集，北京邮电大学，2006。

### 3.2 核心发现

该论文明确指出：

> "在利用迈克耳孙干涉仪测平行玻片折射率的实验中，**干涉条纹的位置和形状会出现与常规不同的现象**。"

论文阐述了**两种不同方法**测量平行玻片的折射率：

1. **方法一**：利用干涉条纹出现的**位置**来测量
   - 即本文档讨论的方法：白光零级条纹的定位
   - 对应等效劈尖模型

2. **方法二**：利用干涉条纹的**移动数目**来测量
   - 即等倾圆环吞吐计数法
   - 对应光程差模型

### 3.3 意义

该论文来自正式学术会议，表明"条纹异常现象"是教学界公认的问题，不是个别实验误差。两种方法对应两种不同的物理模型，各有适用场景。

## 四、补偿板 G₂ 不对称效应

### 4.1 补偿板的原始作用

在标准迈克尔逊干涉仪中：

- G₁（分光板）：光束1穿过一次，光束2穿过三次（透射→反射→再透射）
- G₂（补偿板）：材质厚度与 G₁ 相同，插入光束2路径中，使两束光在玻璃中的路径长度相等

补偿板的作用是消除**色散效应**——使不同波长的光在玻璃中走相同距离，保证白光干涉时各波长零级重合。

### 4.2 插入待测玻璃板后

插入待测玻璃板在 M₁ 臂后：

- 光束1在玻璃中的总路径 = G₁ 中的路径 + 待测玻璃板中的路径（2d）
- 光束2在玻璃中的总路径 = G₁（部分）+ G₂

两束光在玻璃中的路径不再相等，补偿被打破。

### 4.3 可能的次级效应

- **色散失配**：不同波长在待测玻璃板中的折射率不同（$n$ 是 $\lambda$ 的函数），白光零级位置可能轻微偏移
- **热效应**：玻璃板吸收部分光能，局部温度变化可能影响条纹
- **评估**：这些是二级效应，不会改变 M₁ 移动方向的定性结论

## 五、玻璃板内部多次反射效应

### 5.1 Fabry-Perot 效应

待测玻璃板的两平行表面构成一个低精细度的法布里-珀罗标准具。

光在玻璃板两个表面之间可能发生多次反射：
- 主透射光束：直接穿过
- 二次反射光束：在板内往返一次后再透射，强度为主光束的 $R^2$ 倍（$R \approx 4\%$ 对于未镀膜玻璃）

### 5.2 对干涉条纹的影响

- 二次反射光束与主光束之间有时延，相当于一个微弱的"鬼像"
- 在白光干涉中，由于白光相干长度极短（~μm），二次反射的时延远超相干长度，**不会与主光束干涉**
- 但可能略微降低条纹对比度

### 5.3 结论

多次反射效应可以**忽略**。不会改变条纹出现的位置条件。

## 六、两种测量方法的公式对照

### 6.1 数条纹法（等倾干涉）

**原理**：保持 M₁ 与 M₂' 平行（等倾条件），插入玻璃板后，因光程差突变，等倾圆环会吞吐 $N$ 个条纹。

$$2d(n-1) = N\lambda$$

**折射率公式**：$n = 1 + \dfrac{N\lambda}{2d}$

这等价于光程差模型的公式 $n = 1 + \Delta x/d$（因为 $\Delta x = N\lambda/2$）。

**M₁ 移动方向**：在此方法中，若要通过移动 M₁ 使条纹恢复原状，M₁ 需**靠近 G₁**，移动量 $d(n-1)$。

### 6.2 白光等厚条纹定位法

**原理**：先用白光找到零级条纹（等效薄膜厚度为零），插入玻璃板后条纹消失，移动 M₁ 直到再次在**同一视场位置**出现白光零级条纹。

**折射率公式**：$n = \dfrac{d}{d - \Delta x}$

**M₁ 移动方向**：M₁ 需**远离 G₁**，移动量 $d(n-1)/n$。

### 6.3 关键区别

两种方法测量的是**不同的物理量**：

| 方法 | 测量的物理量 | 物理条件 |
|------|------------|---------|
| 数条纹法 | 光程差变化量 $\delta$ | $\delta_{\text{新}} = \delta_{\text{旧}}$ |
| 白光定位法 | 等效薄膜厚度 $h$ | $h_{\text{新}} = h_{\text{旧}} = 0$ |

**在无玻璃板时，$\delta = 0 \iff h = 0$，两种方法等价。有玻璃板时，两者不再等价。**

## 七、G₁ 半反射面的相位跃变

### 7.1 问题

G₁ 的半反射膜通常镀在朝向 M₂ 的面上。光束1（到 M₁）经空气-玻璃界面透射，光束2（到 M₂）经半反射膜反射。反射可能引入 $\pi$ 相位跃变，而透射不引入。

### 7.2 对实验中方向判断的影响

无论是否存在相位跃变，它都是系统性的、固定的相移：
- 无玻璃板时，白光零级条纹出现在两臂满足特定相位关系的位置
- 插入玻璃板后，此相位关系被打破，需通过移动 M₁ 恢复

$\pi$ 相移相当于 $\lambda/2$ 的光程差，对于白光（多种波长）来说，这不改变"零级定位"的逻辑。

### 7.3 结论

相位跃变可能影响零级条纹是"亮纹"还是"暗纹"，但不会改变 M₁ 的移动方向。

## 八、M₁ 位置读数的"零点"问题

### 8.1 实际操作中的注意事项

实验中 M₁ 的位置读数来自千分尺/微动手轮。两次读数（插入前和插入后）的差值 $\Delta x$ 需要仔细处理：

- **空程误差**：丝杠传动存在回程差，M₁ 必须始终沿同一方向移动
- **读数零点**：千分尺的绝对零位与干涉仪的绝对零光程位置通常不对应

### 8.2 对测量的影响

如果实验者在插入玻璃板后，沿**错误方向**转动微动手轮，可能：
- 反向转动时，由于空程，读数值变化了但 M₁ 实际未移动
- 导致 $\Delta x$ 读数不准

### 8.3 确保方向正确的方法

插入玻璃板后，继续沿**未插入时移向零级条纹的同一方向**转动微动手轮。如果发现条纹越来越偏离等厚形态（圆环越来越多），说明方向反了——这正是视像位移效应的直接体现。

## 九、教学争议的来源分析

### 9.1 为什么多数教材使用光程差公式

大多数大学物理实验教材给出的公式是：

$$n = 1 + \frac{\Delta x}{d}$$

原因：
1. 光程差推导**直观简单**，容易被学生理解
2. 多数教材默认使用**等倾干涉数条纹法**（激光光源，单色光）
3. 没有区分"等倾圆环吞吐数"和"白光等厚零级定位"这两种不同的测量策略

### 9.2 为什么实验现象与教材公式矛盾

使用白光等厚条纹法时：
- 实验条件不同：寻找的是 $h = 0$ 而非 $\delta = 0$
- 实验现象与 $n = 1 + \Delta x/d$ 的预测方向相反
- 这引发了"直觉 vs 实验"的矛盾

### 9.3 潘峰论文的价值

潘峰的论文正式确认了这一矛盾的存在，并将其作为学术讨论的议题，而非简单地归为"操作失误"。这为理解两种模型的差异提供了权威参考。
