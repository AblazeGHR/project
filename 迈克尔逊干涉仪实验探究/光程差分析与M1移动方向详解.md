# 迈克尔逊干涉仪：插入玻璃板后为何 M₁ 需要远离 G₁？

## 一、仪器配置（以实验图为准）

```
         M2'（虚线，M2的虚像）
          |
         M₁（可移动镜，上方垂直臂末端）
          |
        [玻璃板] 厚度 d，折射率 n
          |
      S → G1—G2 ——————→ M₂（固定镜，右侧水平臂末端）
          |
          ↓
          E（观察屏）
```

| 元件 | 位置 | 说明 |
|------|------|------|
| M₁ | 上方垂直臂末端 | **可移动镜**，调节臂1（垂直臂）长度 |
| M₂ | 右侧水平臂末端 | **固定镜**，臂2（水平臂）长度不变 |
| G₁ | 中央右侧，45° | **分光板**，将光束一分为二 |
| G₂ | 中央左侧，45° | **补偿板**，平衡两臂玻璃光程 |
| 玻璃板 | 垂直臂中，M₁ 正下方 | 待测玻璃板，厚度 $d$，折射率 $n$ |
| 光源 S | 左侧 | 入射光水平向右 |
| 观察屏 E | 下方 | 观察干涉条纹 |

---

## 二、补偿板 G₂ 的作用（理解光程差的基础）

光源 S 发出的光进入分光板 G₁ 后被分为两束：

- **光束1（垂直臂，走 M₁ 方向）**：
  在 G₁ 镀膜面反射 → 射向 M₂ → M₂ 反射 → 返回 → 再次穿透 G₁ 玻璃到达观察屏
  → **共穿越 G₁ 玻璃 3 次**（比光束1多 1 次）
  

- **光束2（水平臂，走 M₂ 方向）**：
  透射穿过 G₁ 玻璃 → 向上射向 M₁ → M₁ 反射 → 返回穿过 G₁ 玻璃
  → **共穿越 G₁ 玻璃 2 次**


如果没有补偿板，两束光穿越 G₁ 的次数不同，即使两臂几何长度相等，也存在固定的玻璃光程差，且这个差值与波长相关（色散），会导致白光干涉无法实现零光程差。

**G₂ 的作用**：G₂ 与 G₁ 材质、厚度完全相同，平行放置于垂直臂中。光束1 在经过 G₂ 时额外多穿越 1 次玻璃，从而使两束光穿越玻璃的总次数相等（均为 3 次）。

> **结论：G₂ 补偿后，两臂的玻璃光程完全对称，光程差只由两臂的几何长度差决定。**

---

## 三、无玻璃板时的光程差（初始状态）

设：
- $L_1$：臂1的几何长度（G₁ 到 M₁ 的距离）
- $L_2$：臂2的几何长度（G₁ 到 M₂ 的距离，固定不变）

由于 G₂ 已补偿玻璃光程，两束光的**光程差**为：

$$\delta = 2L_1 - 2L_2$$

> 系数 2 是因为光在每条臂中来回走了两次。

**调节 M₁（可移动镜）使 $L_1 = L_2$，则 $\delta = 0$。**

此时在观察屏上，由于各方向入射角的光程差都趋近于零（而非仅某一角度为零），等倾干涉的圆形条纹会向中心收缩，最终变为一片均匀的亮场——即出现**等厚干涉（平行直条纹）**，这标志着"零光程差"位置。

记此时 M₁ 的位置读数为 $x_0$。

---

## 四、插入玻璃板后的光程差（核心分析）

现在在**臂1（垂直臂）**中、M₁ 正下方插入厚度为 $d$、折射率为 $n$ 的玻璃板。

### 4.1 玻璃板对光程的影响

光穿过一段几何厚度为 $d$、折射率为 $n$ 的玻璃时：

- **几何路径长度**：$d$（和空气中一样）
- **等效光程（光学路径）**：$nd$
- **相比同样几何厚度的空气**，多出的光程：$nd - d = d(n-1)$

光束1 在臂1 中**来回各穿越玻璃板一次**，因此总共多出的光程为：

$$\Delta_{\text{玻璃}} = 2 \times d(n-1) = 2d(n-1)$$

### 4.2 插入后的光程差公式

插入玻璃板后，臂1的光程 = 原来几何光程 $2L_1$ + 玻璃额外贡献 $2d(n-1)$

$$\delta' = \underbrace{2L_1 + 2d(n-1)}_{\text{臂1总光程}} - \underbrace{2L_2}_{\text{臂2总光程}}$$

由于插入玻璃板之前，M₁ 停在 $L_1 = L_2$ 的位置（即 $x_0$），代入得：

$$\delta' = 2L_1 + 2d(n-1) - 2L_1 = 2d(n-1) > 0$$

**玻璃板让臂1的光程凭空增加了 $2d(n-1)$，打破了原有的零光程差平衡。**

---

## 五、要重新实现 δ = 0，M₁ 应该如何移动？

要让 $\delta' = 0$，需要：

$$2L_1' + 2d(n-1) - 2L_2 = 0$$

$$L_1' = L_2 - d(n-1) = L_1 - d(n-1)$$

即：M₁ 新的几何位置 $L_1'$ **比原来的 $L_1$ 小了 $d(n-1)$**。

$$\boxed{L_1' = L_1 - d(n-1) \quad \Rightarrow \quad \text{M₁ 需要靠近 G₁}}$$

等等——这与题目中说的"需要远离"**矛盾**。

---

## 六、解开矛盾：M₁ 到底往哪边移？

关键在于理解 M₁ 的运动方向与"靠近 G₁ / 远离 G₁"的关系。

**M₁ 在上方**，G₁ 在下方。

- M₁ **向下移动**（朝向 G₁）→ $L_1$ **减小** → 靠近 G₁
- M₁ **向上移动**（远离 G₁）→ $L_1$ **增大** → 远离 G₁

从上面推导：需要 $L_1' < L_1$，即 **$L_1$ 减小**，即 **M₁ 向下移动，靠近 G₁**。

### 那为什么实验上观察到的是"M₁ 远离（向上移动）才出现等厚条纹"？

这里需要澄清一个关键的物理细节：

---

## 七、等效虚像模型：真正理解"等厚干涉出现的条件"

迈克尔逊干涉仪的干涉，可以等效为 M₁ 与 M₂ 的虚像 **M₂'** 之间形成的"等效空气薄膜"发生干涉。

其中：
- **M₂'** 是 M₂ 经过 G₁ 的反射面形成的虚像，其位置由 G₁ 的厚度决定，**固定不动**。
- **M₁** 可以移动，改变它与 M₂' 的相对位置。

### 插入玻璃板对 M₁ 等效位置的影响

插入折射率 $n$、厚度 $d$ 的玻璃板后，光穿越玻璃板的光程比相同几何厚度的空气大 $d(n-1)$。

这在等效空气薄膜模型中，**等效于把 M₁ 向远离 G₁ 的方向（向上）移动了 $d(n-1)$**。

> **直觉解释**：玻璃让光"走得更慢"，等效于光在空气中走了更长的路。在等效模型里，就好像 M₁ 被推远了 $d(n-1)$。

设 M₁ 的"等效光学位置"为 $L_1^{\text{eff}}$：

$$L_1^{\text{eff}} = L_1 + d(n-1)$$

等效空气薄膜厚度 = M₁ 等效位置与 M₂' 位置之差：

$$h = L_1^{\text{eff}} - L_{M_2'} = L_1 + d(n-1) - L_{M_2'}$$

插入玻璃板前，在零光程差位置有 $L_1 = L_{M_2'}$，因此插入后：

$$h = L_1 + d(n-1) - L_1 = d(n-1) > 0$$

**等效空气薄膜厚度变大了（M₁ 等效位置被推远），要让薄膜厚度回到零，需要把 M₁ 实际位置向靠近 G₁ 的方向（向下）移动 $d(n-1)$。**

$$L_1^{\text{new}} = L_1 - d(n-1) \quad \Rightarrow \quad h^{\text{new}} = L_1^{\text{new}} + d(n-1) - L_1 = 0 \checkmark$$

### 结论

> **M₁ 需要靠近 G₁（向下移动）$d(n-1)$ 的距离，才能重新实现等厚干涉。**

如果实验中观察到的是"M₁ 远离才出现等厚条纹"，则说明：

1. M₁ 初始位置并不在零光程差点，而是在其某一侧。
2. 或者，实验中"零光程差点"的位置因玻璃板的引入而**相对于 M₁ 当前位置发生了方向性偏移**，需要根据具体的初始 M₁ 位置与 M₂' 位置的关系来判断。

---

## 八、测量折射率的公式

无论 M₁ 向哪个方向移动，**两次零光程差之间 M₁ 的位移量 $\Delta x$** 都满足：

$$2\Delta x = 2d(n-1)$$

$$\boxed{n = 1 + \frac{\Delta x}{d}}$$

其中：
- $\Delta x$：M₁ 从第一次零光程差位置到第二次零光程差位置的移动距离（干涉仪读数之差）
- $d$：玻璃板厚度（已知）

---

## 九、实验步骤总结

| 步骤 | 操作 | 目的 |
|------|------|------|
| 1 | 不放玻璃板，调节 M₁ 出现平行直条纹 | 找到第一个零光程差位置，记录 M₁ 读数 $x_1$ |
| 2 | 插入玻璃板（M₁ 下方），条纹变为等倾圆形 | 玻璃板引入额外光程差，零光程差被打破 |
| 3 | 调节 M₁（向靠近 G₁ 方向移动），直到再次出现平行直条纹 | 重新找到零光程差位置，记录 M₁ 读数 $x_2$ |
| 4 | 计算 $\Delta x = \|x_1 - x_2\|$，代入公式 $n = 1 + \Delta x / d$ | 得出折射率 $n$ |
