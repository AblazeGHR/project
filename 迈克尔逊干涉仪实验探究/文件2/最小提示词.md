**关键信息速记**
- **目的**: 用迈克尔逊干涉仪测两块不同厚度/类型玻璃的折射率；比较激光与白光下M1移动方向与原因。
- **激光（He-Ne）要点**: 长相干长→以几何虚像重合为准；插入玻璃后为恢复平直条纹，需将 M1 向远离分光板方向移动。
- **激光折射率公式**: **n = d / (d - Δx)**，其中 Δx = d1 - d0（mm），实验组平均 Δx ≈ 2.79678 mm。
- **白光要点**: 短相干长→以光程差为准；插入玻片后为恢复彩色平行条纹，需将 M1 向靠近分光板方向移动。
- **白光折射率公式**: **n = 1 + Δx / d**，其中 Δx = d1 - d0（mm），实验组平均 Δx ≈ 1.72266 mm。
- **测量流程速记**: 记录无片参考位 d0 → 插入样片 → 调整 M1 恢复目标条纹（激光：平直条纹；白光：中心彩色条纹）→ 记录 d1 → Δx = d1 - d0 → 重复取平均。
- **定义与常用关系**: 虚像位移≈ d(1 - 1/n)；单程光程增量≈ d(n - 1)，双程乘以2。
- **实验注意事项**: 保证玻璃垂直入射并记录厚度 d；明确位移正负约定（示例：d1 - d0）；标注光源类型、波长、环境温度与不确定度估算；记录每次移动方向（靠近/远离）。
- **建议改进项**: 在报告中分别说明“视像位移机制（激光）”与“光程差机制（白光）”；给出误差来源与不确定度计算；独立精确测量玻片厚度 d 后再代入计算。
