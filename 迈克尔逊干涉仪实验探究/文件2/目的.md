# 物理现象与实验探究

## 一、 实验目的
使用迈克尔逊干涉仪测量两种不同厚度和类型的玻璃片的折射率。同时，探究在不同光源下，插入玻璃片后为了恢复特定的等厚干涉条纹状态，干涉臂动镜（M1）需作出的位置调整规律及其背后的物理机制。

## 二、 仪器配置

严格按照实验仪器图：

```
         M₁'（M₁的虚像）
          ↑
         M₁（可移动镜，上方垂直臂末端）
          ↑
        [玻璃板] 厚度 d，折射率 n
          ↑
      S → G₁—G₂ ——————→ M₂（固定镜，右侧水平臂末端）
          |
          ↓
         E（观察屏）
```

| 元件 | 位置 | 说明 |
|------|------|------|
| M₁ | 上方垂直臂末端 | **可移动镜**，沿垂直方向上下移动 |
| M₂ | 右侧水平臂末端 | **固定镜**，位置不变 |
| M₂' | M₂ 经 G₁ 反射面形成的虚像 | 位置固定，是干涉的参考面 |
| G₁ | 左侧 45° 平板 | **分光板**，半透半反 |
| G₂ | 右侧 45° 平板 | **补偿板**，材质厚度同 G₁ |
| 玻璃板 | 垂直臂中，M₁ 正下方 | 待测样品，厚度 $d$，折射率 $n$ |

## 三、 实验测量方法
1. **基础状态调试**：在干涉臂中不放置玻璃片时，调整可移动反射镜 M1 的位置，使得视场中出现平行干涉条纹（若使用白光光源则为彩色平行条纹）。记录此时 M1 的位置读数。
2. **介入介质测试**：在干涉仪的等效光路（M1所在的垂直臂）中垂直插入厚度为已知量 $d$ 的玻璃片。放置后，原有的平行干涉条纹因光程与等效厚度改变而发生变化。
3. **条纹补偿与记录**：再次平移调整 M1，直到视场中重新出现清晰的平行干涉条纹。记录此时 M1 的新位置读数。
4. **折射率计算**：计算出插入玻璃片前后，两次出现平行条纹时 M1 所需要移动的距离差（位置改变量 $\Delta x$），并利用已知的玻璃片厚度 $d$，计算对应玻璃片的折射率 $n$。

## 四、 两次对比实验的实际观测记录
根据实际观测，不同光源和玻璃厚度组合下，需要恢复平行条纹时 M1 的移动方向呈现出了明显的差异现象（注意：以下记录严格以实际观察到的现象为准，个别现象可能与库内其它文件的常规推断存在矛盾）：

### 实验一：红激光 + 厚玻璃板
* **光源类型**：红光激光（单色光）
* **介质参数**：厚玻璃板
* **观测现象**：红光进入仪器，顺利调出平行干涉条纹后，插入厚玻璃板。为再次获得平行干涉条纹，**必须使得 M1 向远离的方向移动**。

### 实验二：白光 + 薄玻璃板
* **光源类型**：白光（宽带复合光）
* **介质参数**：薄玻璃板
* **观测现象**：白光进入仪器，调出彩色平行条纹后，插入薄玻璃板。与实验一截然相反，此时**需要使 M1 向靠近的方向移动**，才能再次观察到相应的彩色平行干涉条纹。
